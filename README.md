# A股模拟交易系统 v1.0.1

专业级A股模拟交易系统，基于FastAPI + Vue3 + ECharts构建。

## 版本信息

- **版本号**：v1.0.1
- **发布日期**：2026-04-23
- **状态**：正式发布

## 功能特性

### 行情交易
- **实时行情**：5秒自动刷新，支持全市场股票搜索
- **专业图表**：分时图（实时到当前时间）、K线图（日/周/月K）
- **完整交易**：T+1制度、涨跌停限制、100股整数倍、市价成交
- **持仓管理**：成本价、浮动盈亏、实时市值计算
- **五档盘口**：买卖五档行情实时展示
- **资金管理**：买入扣减资金、卖出增加资金，总资产自动计算

### K线图时间范围
- **日K**：约3个月（65条数据）
- **周K**：约1年3个月（65条数据）
- **月K**：约5年3个月（63条数据）

### 用户界面
- **三栏布局**：左侧股票列表、中间行情图、右侧详情
- **自选股管理**：搜索添加、自选列表、移除自选
- **板块浏览**：行业板块分类快速切换
- **我的持仓**：右侧栏显示持仓股票，点击快速切换
- **快捷交易**：-100/+100、1手/5手/10手、全仓

## 技术栈

- 后端：FastAPI + SQLAlchemy 2.0 + aiohttp + APScheduler
- 前端：Vue3 + Axios + ECharts 5 + Bootstrap5
- 数据库：SQLite（trading_system.db）

## 数据库表结构

1. **system_account** - 系统单一账号（资金、总资产）
2. **stock_info** - 股票基础信息
3. **stock_rt** - 实时行情（含五档盘口）
4. **kline_data** - K线数据
5. **orders** - 交易订单
6. **positions** - 持仓

## 后端API

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/account` | GET | 账号信息 |
| `/api/positions` | GET | 持仓列表 |
| `/api/orders` | GET | 历史交易记录 |
| `/api/order` | POST | 创建订单（买入/卖出） |
| `/api/stock/list` | GET | 股票列表 |
| `/api/stock/search` | GET | 股票搜索 |
| `/api/stock/realtime` | GET | 实时行情 |
| `/api/stock/kline` | GET | K线数据（日/周/月） |
| `/api/stock/timeline` | GET | 分时数据 |
| `/api/sectors` | GET | 板块分类 |
| `/api/market/overview` | GET | 市场概况 |
| `/api/watchlist` | GET/POST/DELETE | 自选股管理 |

## 交易规则

1. **T+1制度**：当日买入的股票，次日才能卖出
2. **100股整数倍**：每手100股，最小交易量100股
3. **涨跌停限制**：涨停不能买，跌停不能卖
4. **市价成交**：以当前市场价格立即成交

## 快速启动

```bash

# 激活虚拟环境
```

## 系统默认账号

- 无需登录，打开即用
- 初始虚拟资金：100,000 元

## 快捷操作

- `-100` / `+100`：调整交易数量
- `1手` / `5手` / `10手`：快速设置交易数量（100/500/1000股）
- `全仓`：最大可交易数量

## 数据来源

- 实时行情：新浪财经API
- K线数据：新浪财经历史K线API（日K真实数据，周K/月K聚合生成）
- 分时数据：实时生成（基于当前价格）
